# Security policy

Security reports for the current 1.2.0 source line are welcome at
[support@credonomics.in](mailto:support@credonomics.in).

Include affected version, reproducible steps, likely impact and a minimal
synthetic example when possible. Do not send customer documents, credentials
or unrelated personal information. Ask for an appropriate transfer method if
the report contains sensitive attachments.

Please avoid publishing sensitive exploitable details before coordinated
review. We do not promise a response deadline or a bounty. Review and fixes
depend on the issue and available information.

Treat input documents as untrusted. Keep Python, dependencies, converters and
Windows drivers updated, and protect local records and exported files using
appropriate OS permissions. The project does not guarantee that any release
is free from vulnerabilities.
