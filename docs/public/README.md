## Set the GitHub social preview

The asset is prepared; committing it does not configure GitHub's social preview.
A repository administrator can upload `github-social-preview.png` through:

**Repository → Settings → General → Social preview → Edit → Upload an image.**

Use the PNG at its original 1280 × 640 dimensions.
